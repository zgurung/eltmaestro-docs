    Menus in depth¶

    Part 3 of the ELTMaestro User Guide. A reference for every main-window menu item. For the quick map see Menu bar at a glance; items covered in depth elsewhere are cross-linked.

    File¶

    Item What it does
    Create Work Flow Starts a new workflow — same as New on the Workflow(s) tab → Creating a workflow.
    Theme Switches the client theme: Light, Blue, Dark, Dark Blue, or Use System Theme. (Palettes via ThemeManager — see WPF-CLIENT.md.)
    Exit Closes the client.

    Administration¶

    Item What it does
    Configure Maestro Server Opens the Admin Interface — connections, users, integrator config (admin-role only).
    Metrics Configuration ▸ Control Test The Manage Control Tests window — define data-quality / reconciliation control tests that run against your data. Full walkthrough: Managing control tests.
    Metrics Configuration ▸ Data Quality Management The Data Quality Management console for managing those checks.
    Workflow Configuration ▸ Job Watermarks Watermark Management — view/manage the incremental-load high-water marks that CDC / incremental steps advance.
    Workflow Configuration ▸ Email Alerts Email Alert Management — configure email notifications on workflow events (e.g. success/failure).
    Scheduler The Cron Scheduler — schedule workflows to run on a cron expression. Full walkthrough: Scheduling a workflow.
    Migration ▸ Export Workflow(s) Package workflows from the server to local files (server → local).
    Migration ▸ Import Workflow(s) Load workflows from local files onto the server (local → server).

    Runtime & Logs¶

    Item What it does
    Logging ▸ Workflow Logs The run-log dashboard (scoped to the selected workflow, if any) — browse batch runs and drill into step logs. This is the main monitoring entry point.
    Logging ▸ Server Logs The meta-service / server log viewer.
    Reports ▸ Metrics Report Workflow / warehouse metrics report.
    Runtime Operations Runtime Ops — see and manage currently-running workflows (running processes), halt runs, etc. See OPERATIONS.md.

    Help¶

    Item What it does
    About Version / build information.
    License Information Current license and expiry.

    See also: Workflows (the Scheduler, Email Alerts, and Workflow Logs all act on workflows) and Administration & Setup.
